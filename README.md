# YouTube Feed Control

> **Manifest V3 Chrome Extension** providing a user-controlled filtering layer over YouTube recommendations.

[![CI](https://github.com/user/youtube-feed-control/actions/workflows/ci.yml/badge.svg)](https://github.com/user/youtube-feed-control)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

---

## What It Does
- **Whitelists feeds by Genre & Subgenre**: Only videos matching your enabled genres/subgenres appear on filtered recommendation surfaces.
- **Complete Shorts Blocker**: Removes all Shorts entry points (shelves, cards, guide items) and redirects direct `/shorts/<id>` URLs to the normal YouTube player.
- **Smart Diversity Engine**: Prevents algorithmic fatigue by capping channels to at most 2 videos per session, suppressing duplicates, and preventing repetitive subgenres.
- **Duration Limits**: Independent min/max boundaries resolved `subgenre → genre → global`.
- **Content Type Filtering**: Filters by video structure (tutorials, reviews, deep dives, documentaries, experiments, etc.).
- **Hard Blacklisting**: Instantly exclude specific videos, channels, or entire genres/subgenres everywhere, with an interstitial blocking direct URLs.
- **Search Stays Unrestricted**: Search results are never filtered by default.

## What It Does NOT Do
- **It does NOT change YouTube's recommendation algorithm**: Everything runs locally in your browser after YouTube delivers the feed.
- **No backend, no database, no telemetry**: Zero external tracking or data transmission.

---

## 🔒 Privacy First
All settings, classification caches, and blacklist databases are stored strictly inside your local browser via `chrome.storage.local` and IndexedDB. Read our full policy in [PRIVACY.md](PRIVACY.md).

## 🚀 Installation & Development

### 1. Build from source
```bash
# Clone the repository
git clone https://github.com/user/youtube-feed-control.git
cd youtube-feed-control

# Install dependencies
npm install

# Run tests and typecheck
npm test
npm run typecheck

# Build extension
npm run build

# Package for release
npm run zip
```

### 2. Load Unpacked in Chrome
1. Open Google Chrome and navigate to `chrome://extensions/`.
2. Enable **Developer mode** (toggle in the top-right corner).
3. Click **Load unpacked** and select the `dist/` directory generated by `npm run build`.
4. Open [YouTube](https://www.youtube.com) and configure your filters in the Options page.
